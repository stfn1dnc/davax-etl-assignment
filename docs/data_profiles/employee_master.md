# Employee Master Data

## Purpose

The Employee Master dataset is used to build the Employee Dimension
(DIM_EMPLOYEE) required by the analytical Star Schema.

## Source

No standalone Employee Master Data file was provided.

The dataset is generated from the following operational sources:

- Meeting1 1.csv
- Meeting2 1.csv
- Meeting3 1.csv
- Timesheet__WorkedHours 1.csv
- Timesheet_Absences 1.csv

Exam_Absences 1.csv is not used to generate Employee Master because it
does not contain employee email.

## Business Key

Employee Email

Business Key Rule:

LOWER(TRIM(email))

## Available Source Attributes

- Employee Name
- Employee Email

## Generated Attributes

The following attributes will be generated by the ETL process:

- Grade
- Discipline
- Line Manager
- Delivery Unit

These values are generated using deterministic business rules.

## Target

TARGET.DIM_EMPLOYEE
